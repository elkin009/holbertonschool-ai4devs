# Setup Environment Notes

## Environment Details
- **IDE:** Visual Studio Code (VS Code)
- **AI Assistant:** GitHub Copilot
- **Operating System:** Ubuntu (Environment via Holberton)

## Installation Steps
1. **VS Code Extensions:** Opened the Extensions view (Ctrl+Shift+X) and searched for "GitHub Copilot".
2. **Authentication:** Installed the extension and signed in with GitHub account to activate the license.
3. **Verification:** Verified that the Copilot icon appears in the bottom status bar.
4. **Additional Tools:** Installed WakaTime for automated time tracking during the sprint.

## Versions
- **VS Code:** 1.85.0+
- **GitHub Copilot Extension:** Latest stable
- **Node.js:** v18.x (for project environment)
