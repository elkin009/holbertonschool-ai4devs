## User Story 1
As a new user, I want to register with my email and password so that I can securely access my decision history.

## User Story 2
As a returning user, I want to log in to my account so that I can view and manage my past decisions.

## User Story 3
As a user, I want to input a decision description so that AI can analyze it and generate pros and cons.

## User Story 4
As a user, I want to see a structured list of pros and cons so that I can evaluate my options clearly.

## User Story 5
As a user, I want to add my own pros and cons manually so that I can include personal context the AI may have missed.

## User Story 6
As a user, I want to vote for my preferred option so that I can record my final decision.

## User Story 7
As a user, I want to view my decision history so that I can reflect on past choices and their outcomes.

## User Story 8
As a user, I want to delete a decision from my history so that I can keep my workspace clean and relevant.
