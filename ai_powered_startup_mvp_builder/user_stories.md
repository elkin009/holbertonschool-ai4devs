## User Story 1
As a new user, I want to register with my email and password so that I can securely access my personal task list.

## User Story 2
As a returning user, I want to log in to my account so that I can view and manage my tasks from any device.

## User Story 3
As a user, I want to create a new task with a title, description, and due date so that I can keep track of what needs to be done.

## User Story 4
As a user, I want to set a priority level for each task so that I can focus on the most important work first.

## User Story 5
As a user, I want to update the status of a task so that I can track my progress over time.

## User Story 6
As a user, I want to filter tasks by status so that I can quickly see only the tasks relevant to my current focus.

## User Story 7
As a user, I want to search tasks by keyword so that I can find a specific task without scrolling through the entire list.

## User Story 8
As a user, I want to delete a task so that I can remove items that are no longer relevant.
