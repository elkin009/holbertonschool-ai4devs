## User Story 1
As a new user, I want to register with my email and password so that I can securely access my personal task list.
**Acceptance Criteria:** User can submit a registration form with email and password. System creates an account and redirects to the dashboard.

## User Story 2
As a returning user, I want to log in to my account so that I can view and manage my tasks from any device.
**Acceptance Criteria:** User can enter credentials and receive a JWT token. Invalid credentials show an error message.

## User Story 3
As a user, I want to create a new task with a title, description, and due date so that I can keep track of what needs to be done.
**Acceptance Criteria:** User fills in task form and submits. New task appears in the task list immediately.

## User Story 4
As a user, I want to set a priority level (Low, Medium, High) for each task so that I can focus on the most important work first.
**Acceptance Criteria:** User can select priority when creating or editing a task. Tasks are visually distinguished by priority level.

## User Story 5
As a user, I want to update the status of a task (To Do, In Progress, Done) so that I can track my progress over time.
**Acceptance Criteria:** User can change task status via a dropdown. Status change is saved and reflected instantly in the UI.

## User Story 6
As a user, I want to filter tasks by status so that I can quickly see only the tasks relevant to my current focus.
**Acceptance Criteria:** Filter buttons for each status are available. Selecting a filter shows only matching tasks.

## User Story 7
As a user, I want to search tasks by keyword so that I can find a specific task without scrolling through the entire list.
**Acceptance Criteria:** A search input filters tasks by title or description in real time as the user types.

## User Story 8
As a user, I want to delete a task so that I can remove items that are no longer relevant.
**Acceptance Criteria:** User clicks delete button and confirms. Task is permanently removed from the list.

## User Story 9
As a user, I want to edit an existing task so that I can update details when requirements change.
**Acceptance Criteria:** User can open a task, modify any field, and save. Changes are reflected immediately in the task list.

## User Story 10
As a user, I want to see a dashboard summary showing total, in-progress, and completed tasks so that I can get a quick overview of my productivity.
**Acceptance Criteria:** Dashboard displays counters for each task status. Counts update automatically when tasks are modified.
