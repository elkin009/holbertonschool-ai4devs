# MVP Concept - Task Management App

## Problem Statement
Small teams and freelancers struggle to organize, prioritize, and track their daily tasks efficiently. Existing tools are either too complex or too expensive for small teams, leaving them without a simple, focused solution.

## Target Users
- Freelancers managing multiple projects
- Small startup teams (2-10 people)
- Students organizing academic tasks
- Remote workers tracking daily goals

## Core Features
- Task creation with title, description, and due date
- Task status management (To Do, In Progress, Done)
- Filter and search tasks by status or keyword
- Priority levels (Low, Medium, High) for each task
- Simple dashboard showing task summary and progress

## Constraints
- No payment or subscription system
- Maximum 200 tasks per user
- No real-time collaboration in MVP phase
- Basic authentication only (email and password)
